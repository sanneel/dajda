# პასუხისმგებლიანი გამოყენება

ბოლო განახლება: 31.08.2026

## 1. სტატისტიკა წარსულია და არა დაპირება

1.1. პლატფორმაზე ნაჩვენები ყველა მაჩვენებელი, მათ შორის სიზუსტე და შედეგი ერთეულებში, აღწერს უკვე დასრულებულ მოვლენებს. წარსული შედეგი არ განსაზღვრავს მომავალს და არავითარი მაჩვენებელი არ არის მოგების გარანტია.

1.2. არც პლატფორმა და არც რომელიმე ავტორი არ გპირდებათ მოგებას. ვინც მოგებას გპირდებათ, გატყუებთ.

## 2. რატომ ვაჩვენებთ წაგებულ პროგნოზებსაც

2.1. ყველა ავტორის სტატისტიკაში აისახება როგორც გამართლებული, ისე გაუმართლებელი პროგნოზი. გამოქვეყნებული ჩანაწერი უცვლელია, ამიტომ ისტორიის გალამაზება შეუძლებელია.

2.2. ეს პლატფორმის მთავარი პრინციპია: თუ სადმე მხოლოდ მოგებულ პროგნოზებს ხედავთ, ეს იმას ნიშნავს, რომ წაგებულები წაშალეს.

## 3. მცირე ისტორია ბევრს ვერ გეტყვით

3.1. რამდენიმე პროგნოზზე დაფუძნებული მაღალი მაჩვენებელი შემთხვევითობის შედეგიც შეიძლება იყოს. რაც მეტია ჩანაწერი, მით მეტს ამბობს სტატისტიკა. ავტორის შეფასებისას ყურადღება მიაქციეთ პროგნოზების საერთო რაოდენობას და არა მხოლოდ პროცენტს.

## 4. ასაკობრივი შეზღუდვა

4.1. პლატფორმა განკუთვნილია მხოლოდ 18 წლის და მეტი ასაკის პირებისთვის.

## 5. თუ თამაში პრობლემად იქცა

5.1. საყურადღებო ნიშნებია: თამაშობთ იმაზე მეტით, ვიდრე შეგიძლიათ დაკარგოთ; ცდილობთ წაგებულის დაბრუნებას ფსონის გაზრდით; მალავთ თამაშს ახლობლებისგან; თამაში ხელს გიშლით სამსახურში, სწავლაში ან ურთიერთობებში.

5.2. ასეთ შემთხვევაში: შეწყვიტეთ თამაში და ესაუბრეთ ახლობელს; მიმართეთ ფსიქოლოგს ან ფსიქიკური ჯანმრთელობის ცენტრს; ისარგებლეთ სახელმწიფო თვითშეზღუდვის მექანიზმით და მოითხოვეთ აზარტულ თამაშებზე დამოკიდებულ პირთა რეესტრში შეყვანა, რაც აზარტული თამაშების ორგანიზატორებთან წვდომას ზღუდავს.

5.3. დახმარების თხოვნა სირცხვილი არ არის.

## 6. რას ვაკეთებთ ჩვენ

6.1. პლატფორმა არ იღებს ფსონებს და არ არის აზარტული თამაშების ორგანიზატორი; აქ იყიდება მხოლოდ ანალიტიკური კონტენტი.

6.2. ავტორებს ხელშეკრულებით ეკრძალებათ მოგების გარანტირება და გარანტიის შთაბეჭდილების შექმნა.

6.3. ყველა მაჩვენებელს თან ახლავს შეხსენება, რომ ის წარსულ შედეგებს ასახავს.
